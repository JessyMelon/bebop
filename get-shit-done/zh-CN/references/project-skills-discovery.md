# 项目技能发现

在执行前，检查项目定义的技能并应用其规则。

**发现步骤（所有 GSD agent 共享）：**
1. 检查 `.claude/skills/` 或 `.agents/skills/` 目录，如果两者都不存在则跳过。
2. 列出可用技能（子目录）。
3. 读取每个技能的 `SKILL.md`（轻量索引，通常约 130 行）。
4. 仅在当前任务需要时再加载特定的 `rules/*.md` 文件。
5. 不要加载完整的 `AGENTS.md` 文件，它们很大（100KB+），会消耗大量上下文。

**应用方式** - 如何应用已加载规则取决于调用方 agent：
- 规划器在计划中考虑项目技能模式和约定。
- 执行器遵循与当前实现任务相关的技能规则。
- 研究器确保研究产出考虑项目技能模式。
- 验证器在扫描反模式和验证质量时应用技能规则。
- 调试器遵循与所调查 bug 和所应用修复相关的技能规则。

调用方的 agent 文件应说明适用哪种应用方式。
