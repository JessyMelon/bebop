# GSD 指令

- 当用户请求 GSD 或使用 `gsd-*` 命令时，使用 get-shit-done 技能。
- 将 `/gsd-...` 或 `gsd-...` 视为命令调用，并从 `.github/skills/gsd-*` 加载匹配文件。
- 当命令要求启动 subagent 时，优先使用 `.github/agents` 中匹配的自定义 agent。
- 除非用户明确要求，否则不要应用 GSD 工作流。
- 完成任何 `gsd-*` 命令后（或其触发的任何交付物：功能、bug 修复、测试、文档等），始终执行：(1) 通过 `ask_user` 提示用户下一步；重复这个反馈循环，直到用户明确表示已完成。
